# Atomia

A story about the power of friendship, believing in yourself – and of course – ✨chemistry✨. Unique gameplay that involves real chemistry (kind of) and side quests where you can fight rocks and date atoms!

# What is this branch about?

This branch contains the code for the new and improved titration minigame! Essentially, you are given a scale which is off-balance, and there are two beekers at each end. The far right end has a compounds, while the left is empty. It is your job to titrate! Click the element buttons and balance the scale!

# How to play?

This minigame isn't currently attached to any other game mechanics. To play, download all the files, and run in Unity. Go to the TitrationSceneFinal scene and simply click play!
